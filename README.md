# Cachet Sur Mesure — Votre empreinte

Publicité explicative originale de 25 secondes en Full HD (1920×1080, 30 fps), avec cachet 3D, personnalisation, tamponnage de documents, musique et effets originaux.

- `cachet-sur-mesure.mp4` : vidéo finale H.264 avec audio AAC.
- `cachet-sur-mesure-sources.zip` : projet Hyperframes éditable, modèles procéduraux, polices locales et musique.
- `affiche.png` : aperçu de la scène finale.

Le client a confirmé Cachet Sur Mesure comme marque à promouvoir. La consultation du site fourni était bloquée par le proxy réseau (403). Le contenu s’appuie sur le brief : création de cachets personnalisés pour sociétés, ONG, hôpitaux et écoles. La direction graphique proposée ne prétend pas reproduire une identité officielle vérifiée. Aucun prix ou délai n’est inventé.

Pour télécharger depuis GitHub, ouvrir le fichier puis choisir « Download raw file ».
